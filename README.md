## 🛠️ Features

- **Image Loading**: Reads and parses BMP image files.
- **Image Manipulation**: Applies transformations such as grayscale conversion, image inversion, and other effects.
- **User Interaction**: Provides a command-line interface for users to select and apply image processing operations.
- **File Output**: Saves the processed images to new BMP files.

## 🚀 Getting Started

### Prerequisites

- A C++ compiler supporting C++11 or later (e.g., `g++`, `clang++`).
- A Unix-like environment (Linux, macOS) or Windows with a compatible terminal.

### Compilation

To compile the program, use the following command:

```bash
g++ -std=c++11 -o main hubscher_main.cpp
